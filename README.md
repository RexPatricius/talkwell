# talkwellapp.com

Source for [talkwellapp.com](https://talkwellapp.com), the website for the Talkwell iOS app: a landing page, `/support/` and `/privacy/`.

Plain static HTML and CSS, served by GitHub Pages from `main`. No build step, scripts, cookies, analytics or third-party requests. Keep it that way: anything that tracks visitors needs a consent banner and a privacy policy update first.

Every change goes through a pull request and is approved by the project's governance review before merge.
